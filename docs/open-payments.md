# Herramientas y Recursos

Todo lo que necesitas para llegar listo para el hackatón, en un solo lugar. Tu meta es sencilla: lograr que un pago funcione de principio a fin. Una vez que lo logras, todo lo demás se construye a partir de ahí.

## Paso 1 - Aprende los conceptos

Oriéntate antes de escribir código. Empieza aquí si Open Payments es nuevo para ti.

### Curso de Open Payments en Platzi

Un curso introductorio gratuito que te guía por la tecnología para que llegues al hackatón ya sabiendo cómo funciona.

[Empieza el curso (se abre en una pestaña nueva)](https://platzi.com/cursos/interledger-openpayments/)

### Serie de videos introductorios

Tutoriales cortos que cubren los conceptos básicos del Interledger Protocol y un recorrido a fondo por Open Payments. Sigue el ejemplo con el repositorio open-payments-node y los fragmentos de código de la documentación. (El recurso aún no está disponible en español.)

[Ver los videos (se abre en una pestaña nueva)](https://www.youtube.com/watch?v=HeH1E7mmEh8&list=PLDHju0onYcAJakrsF-I7LK_0phEqurn46)

### Blog de ingeniería

Publicaciones de nuestro equipo de ingeniería que presentan Open Payments, explican por qué elegimos GNAP para la autorización y cubren el Open Payments PHP SDK.

[Leer el blog](https://interledger.org/es/blog/category/engineering/)

## Paso 2 - Consulta el material de referencia

A medida que empiezas a programar, ten estos recursos abiertos en otra pestaña.

### Documentación de Open Payments

Explicaciones detalladas, fragmentos de código, guías de implementación y la especificación completa de la API.

[Leer la documentación (se abre en una pestaña nueva)](https://openpayments.dev/es)

### Open Payments SDK

Tipos de TypeScript generados directamente a partir de las especificaciones OpenAPI de Open Payments, más un cliente de Node.js que firma las solicitudes con tu clave y valida las respuestas contra las especificaciones. (Recurso aún no disponible en español.)

[Instalar el SDK (se abre en una pestaña nueva)](https://github.com/interledger/open-payments-node)

### Glosario de términos

Nuestro glosario de términos puede servirte de guía de referencia mientras avanzas por los recursos y empiezas a construir. (El recurso aún no está disponible en español.)

[Glosario (se abre en una pestaña nueva)](https://openpayments.dev/es/resources/glossary/)

## Paso 3 - Construye y prueba

Herramientas prácticas para que un pago realmente suceda.

### Interledger Test Wallet

Simula un proveedor de servicios financieros con Interledger habilitado. Regístrate, completa un flujo de KYC y mantén un saldo de dinero de práctica para enviar y recibir pagos usando direcciones de wallet. También expone las APIs de Open Payments para que terceros puedan iniciar pagos. (La aplicación aún no está disponible en español.)

[Consigue una Test Wallet (se abre en una pestaña nueva)](https://wallet.interledger-test.dev)

### Repositorios de apoyo en GitHub

Scripts de ejemplo para enviar pagos, una biblioteca de fragmentos de código listos para usar en Visual Studio Code y snippets del Node SDK que funcionan con la Interledger Test Wallet. Para PHP, también están los repositorios PHP Open Payments SDK y Open Payments PHP Snippets. En conjunto, facilitan probar, integrar y experimentar con Open Payments en tu proyecto. (El contenido solo está disponible en inglés.)

[Ver nuestro GitHub (se abre en una pestaña nueva)](https://github.com/interledger)

### Interledger Pay

Una aplicación cliente de pagos peer-to-peer funcional. (La aplicación aún no está disponible en español.)

[Paga a alguien (se abre en una pestaña nueva)](https://interledgerpay.com/)

### Interledger Boutique

Una app de comercio electrónico de ejemplo para probar un flujo de pago de Open Payments de principio a fin. (La aplicación aún no está disponible en español.)

[Haz una compra (se abre en una pestaña nueva)](https://boutique.interledger-test.dev/)
